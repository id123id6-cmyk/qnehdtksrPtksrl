6. 콘텐츠 작성 규칙 (지금까지의 운영 기준)

  1. 사실과 미확정 분리 — 국세청·청약홈·기재부 등 공식 수치만 “확정”으로 씀. 세제개편안 등은 반드시 정부안 / 국회 미통과 명시
  2. 장문·구조화 — H2 다수, 표(post-table), FAQ, 계산 예시, 내부링크 3개 전후
  3. 쉬운 말 — 사회초년생이 읽는다고 가정
  4. 면책 — 세무 대리면책, 투자 권유 금지, 개인 상황 상이 고지
  5. 이미지 — 히어로·썸네일 실제 해상도 맞춤, alt 한국어
  6. 템플릿 — blog/post-56.html / post-57.html 구조 재사용. GA4 / AdSense / Clarity 스크립트는 head에서 유지
  7. 발행 시 6곳 업데이트 — post HTML, blog/index 카드, posts.json(+count), rss.xml, 루트 index 최신글 6개, sitemap URL 1개만 추가

7. AdSense 승인용으로 이미 한 일 / 남은 일

이미 한 일

  • AdSense pub ID · ads.txt · privacy 고지 준비
  • 홈·도구·블로그·소개·정책 페이지 구성
  • 중복 페이지 정리 및 영구 리다이렉트
  • 가치 낮은 글 목록 제외 / noindex
  • 세금·제도 장문 글 강화 (표·FAQ·출처·면책)
  • GA4 / Clarity로 방문 측정 가능 상태

젠팀과 같이 하면 좋은 일 (제안)

  1. AdSense 심사 체크리스트로 전 페이지 감사 — 내비 일관성, 모바일 가독성, 광고 자리 과도함, 클릭 유도 문구
  2. 콘텐츠 밀도·독창성 강화 — thin/유사 글 추가 정리, 도구↔블로그 내부링크
  3. 트래픽·색인 상태 점검 — Search Console / Naver 색인·커버리지
  4. 승인 재신청 타이밍·카피 — 사이트 설명, 카테고리, 유용성 한 줄
  5. 승인 후 광고 UX — 본문 중간/하단 슬롯, CLS 방지, 모바일 과다 광고 방지
